05 / WHERE IT FITSAPPLICATION-AWARE INFRASTRUCTURE

Keep your framework.
Take the files.

magic-infra is for teams that already have an app and want to turn its infrastructure needs into files they can run, review and hand over.

THE MAGIC-INFRA APPROACH

Start from the app you have.

Use Spring signals to suggest resources, declare who manages them, and compile the result to Compose or Kubernetes.

Try the workflow ↗
CLOSEST OVERLAP / PORTABLE WORKLOADS

Score

Write a portable workload spec and generate Compose or Kubernetes manifests with target provisioners. magic-infra adds framework evidence and a plan that explains resource decisions.

Score docs ↗
INFRASTRUCTURE FROM CODE

Encore

Declare infrastructure in Go or TypeScript using Encore’s SDK. Its managed platform is optional, and it supports self-hosting. magic-infra starts with an existing Spring app and generates the deployment files.

Encore docs ↗
LOCAL DEVELOPMENT

Tilt

Configure a Tiltfile to build and live-update Kubernetes or Compose services during development. The files generated by magic-infra could be inputs to that workflow.
